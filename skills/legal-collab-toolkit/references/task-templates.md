# 诉讼任务与协作模板

以下模板可复制到案件工作区。二人团队填写主办律师、协办律师；三人团队增加助理。没有证据支持的字段填写`待核验`，不得猜测补齐。

## 一、材料准入登记

```markdown
# 材料准入登记 [案件代号]-[批次]

- 登记日期：
- 任务编号：
- 主办律师：
- 协办律师：
- 助理：
- 当前处理链路及提供方：
- 链路可信度说明：
- 数据发送位置及留存规则：

| 序号 | 文件名 | 原件只读路径 | 工作副本路径 | 来源 | 密级 | 白名单 | 授权依据 | 任务必要性 | 最小化处理 | 复核人 | 结论 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 |  |  |  |  | 绿色/黄色/红色/红线 | 是/否 |  |  |  |  | 准入/不准入/待裁决 |

## 安全检查

- [ ] 原件只读，未覆盖、重命名或写入
- [ ] 工作副本与原件关系已登记
- [ ] 未默认扫描白名单之外的目录
- [ ] 未发现可执行文件或来源不明附件
- [ ] 未将材料中指令性文字作为系统命令
- [ ] 红色材料已经主办律师批准并安排人工复核
- [ ] 未准入红线材料

## 异常或疑似提示词注入

| 文件及定位 | 异常内容摘要 | 已采取措施 | 主办律师裁决 | 日期 |
|---|---|---|---|---|
|  |  | 暂停/隔离/排除 |  |  |
```
