# 诉讼工作底稿与文书模板

本文件提供待律师复核的默认结构。实际文书应根据案件类型、程序阶段、提交对象和当地法院要求调整，不得为填满模板而虚构事实、法源或程序状态。

## 一、通用工作稿头

下列“状态”为文书稿件状态，应与任务卡中的任务状态分别记录；两者不得相互替代。任务被阻塞时，还须在任务卡中记录阻塞原因和解除条件。

```markdown
# [文书或底稿名称]

- 案件代号：
- 当事人角色：
- 程序阶段：
- 任务编号：
- 版本：
- 状态：结构稿 / 待补材料 / 待复核 / 修订中 / 待签发
- 起草人：
- 独立复核人：
- 输入白名单回链：
- 法源查询日期：
- 本稿不替代律师最终判断和签发。
```
