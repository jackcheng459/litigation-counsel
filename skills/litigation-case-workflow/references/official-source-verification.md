# 法源与程序核验

本文件规定核验方法和回执格式，不预置具体案件的适用结论，也不把固定期限天数写成通用答案。

## 一、核验对象

每项候选法律结论至少拆成以下字段：

| 字段 | 必填内容 |
|---|---|
| 规范名称 | 完整名称，不用简称代替 |
| 制定或发布机关 | 识别规范位阶和来源 |
| 文号 | 有则填写，无则标明未见 |
| 公布与施行日期 | 分开记录 |
| 时效性 | 现行有效、尚未生效、已修改、已废止或待核验 |
| 条文或要点 | 精确到条、款、项；无法定位时不得假装精确 |
| 时间效力 | 结合涉案行为、合同、立案或裁判时间判断 |
| 个案对应 | 写清规范要件与已确认事实如何对应 |
| 原始链接或文件 | 保存可回链位置和访问日期 |
| 核验人及时间 | 区分 AI 候选、起草人核验和律师复核 |

## 二、首选官方入口

以下为核验入口，不等于个案适用结论：

1. 国家法律法规数据库：<https://flk.npc.gov.cn/>。用于检索法律、行政法规、监察法规、地方性法规和司法解释，并核对时效性、公布日期、施行日期及制定机关。
2. 最高人民法院：<https://www.court.gov.cn/>。优先在“权威发布”下核对司法文件、司法解释、指导性案例及其他正式发布材料。
3. 最高人民法院公报：<https://gongbao.court.gov.cn/>。用于复核公报刊载的司法解释、指导性案例和裁判文书选登。
4. 中国裁判文书网：<https://wenshu.court.gov.cn/>。用于检索普通裁判文书；取得结果后仍须核对官方页面、案号、法院、裁判日期、程序阶段和访问日期。
5. 受理法院官方网站、诉讼服务平台、法院正式通知或送达文书。用于核对该院具体提交要求、庭期、举证安排和程序通知。

访问受限、页面失效或只取得搜索摘要时，必须记录失败状态，不得把摘要包装成已核验全文。

## 三、规范核验步骤

1. 从官方入口按完整名称或文号检索。
2. 打开正文，核对发布机关、文号、公布日期、施行日期和时效性。
3. 定位具体条款，同时检查附则、修改决定、废止决定、时间效力解释及相关司法解释。
4. 记录对本案有利、不利和存在歧义的部分，不只摘录支持己方的内容。
5. 将规范要件逐项映射到原件直接支持的事实；当事人陈述和待核事实单独标记。
6. 保存官方链接、访问日期和必要的原文定位。内部工作稿可摘录必要短句，但应以链接或正式文件回链。
7. 由律师判断最终适用、论证层级和是否写入对外文书。

## 四、案例核验步骤

1. 先判断材料类型：指导性案例、公报案例、典型案例、普通裁判文书或二次整理材料。
2. 核对案号、法院、裁判日期、程序阶段、发布机关和来源页面。
3. 提取与本案真正相似和不同的事实，不因案由相同就认定可类推。
4. 核对案例引用的规范在本案时间点是否仍有效、已修改或被新解释影响。
5. 区分指导性案例的参照意义、其他案例的参考意义和二次材料的检索线索作用。
6. 无法取得裁判全文或官方发布页时，标记`仅取得线索，未完成全文核验`。

## 五、期限与程序核验

任何期限结论都必须同时核对：

- 程序类型和当事人身份；
- 法院正式文书或送达材料；
- 送达方式、送达时间和回执；
- 起算、期间计算、顺延和届满规则；
- 法院特别指定、变更或延长情况；
- 计算人、复算人和计算时间。

交付时给出计算底稿和输入值，不只给出一个日期。无法取得送达证据或程序文书时，期限状态保持`待核验`或`阻塞`。

## 六、核验回执模板

```markdown
### 法源核验回执

- 候选结论：
- 规范名称与文号：
- 发布机关：
- 公布日期 / 施行日期：
- 时效性：
- 条文定位：
- 个案事实对应：
- 不利或冲突来源：
- 官方链接 / 文件路径：
- 访问日期：
- 核验状态：已核验全文 / 仅取得线索 / 访问失败 / 待核验
- 起草人：
- 律师复核：待复核 / 已复核
```

## 七、停止条件

出现以下任一情形时，不得输出确定法律结论：

- 官方全文不可得或时效性不明；
- 个案关键日期、程序身份或送达状态不明；
- 同一问题存在相互冲突的现行规范或裁判口径，尚未完成层级分析；
- 只能取得模型记忆、旧底稿、培训资料、自媒体文章或非官方摘要；
- 结论需要律师作策略、证据取舍或风险承担判断。
